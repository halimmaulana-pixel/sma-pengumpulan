# Petunjuk singkat untuk pengumpulan tugas

1. Kumpulkan tugas hanya lewat Issue formulir di repositori ini.
2. Jangan push berkas tugas langsung ke repositori ini. Repositori ini hanya wadah pengumpulan.
3. Setiap revisi setelah penilaian dibalas di Issue yang sama, bukan di Issue baru.
4. Repositori ini bersifat private karena memuat nama dan NIM.
