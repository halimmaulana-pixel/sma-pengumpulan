# Pengumpulan Tugas: Social Media Analytics

Repositori ini dipakai mahasiswa untuk **mengumpulkan tugas** mata kuliah Social Media Analytics (3 SKS), pengampu Dr. Halim Maulana, S.T., M.Kom.

Cara kumulnya sederhana. Mahasiswa membuat repositori sendiri untuk berisi data dan laporan, lalu mengisi formulir Issue di repositori ini. Dosen meninjau lewat Issue yang sama, sehingga revisi tercatat rapi.

---

## Langkah mahasiswa

1. Buat akun GitHub kalau belum punya.
2. Buat repositori baru di akun sendiri, namanya bebas, misalnya `sma-tugas-1-nim`. Pilih **private** kalau isinya memuat nama atau data yang sensitif.
3. Unggah berkas tugasnya ke repositori itu: berkas data, log, laporan, dan bila ada, video.
4. Buka repositori ini, pilih **Issues**, lalu **New issue**, dan pilih formulir **Pengumpulan Tugas**.
5. Isi semua kolom. Tempel tautan repositorimu di kolom yang tersedia.
6. Kirim. Simpan nomor Issue-nya sebagai bukti.

Catatan: temuan tanpa bukti di data sendiri tidak dinilai. Kalau satu bagian laporan ternyata dibantu AI, tulis di laporan (lihat ketentuan tugas).

---

## Yang sering terlupa

- Tautan repositori belum dibuka untuk publik (private) sehingga dosen tidak bisa membuka. Untuk repositori private, undang akun dosen sebagai collaborator, atau buat repo public untuk materi yang tidak sensitif.
- Checksum SHA-256 belum diisi.
- Rekaman penjelasan tidak ada.
- Data mentah masih tercampur dengan data hasil olahan tanpa diberi keterangan.
